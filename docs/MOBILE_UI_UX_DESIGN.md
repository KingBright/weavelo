# Weavelo Air：移动端补充规范

2026-11-08，与 [全平台规范](UI_UX_SPECIFICATION.md) 一起使用。V3 的手机截图同时展示了两类接收控件，实际产品按来源切换，不能把两组胶囊同时压在视频上。

管理界面采用浅云灰背景、白色卡片、蓝色主操作与绿色在线状态。保留设备/网络/权限、扫描邀请、地址连接、发送与文件操作；诊断与技术信息按需展开，真实错误直接可见。

查看电脑时，视频下方保留独立布局区域，放置触控板、直触、键盘、复位四个常用操作。布局变化后重新计算输入逆映射并取消旧手势；复位恢复适配状态。键盘展开时只额外显示快捷键行，关闭后立即释放粘滞键。物理键盘、IME 文本、多指、长按右键和滚动等既有能力保留。

查看手机时，在画面外保留 44dp 本地侧栏，提供 5dp 右侧视觉柄及可操作的触控区域、语义标签和点击替代入口；不得用不可见的宽命中区覆盖远端画面。向内拖动展开；上下拖动调整位置；手柄动作不透传远端。展开后保留返回、支持时的系统桌面、键盘、更多。更多容纳断开、视图调整、来源、声音、文件和设置。独立应用的返回与全屏手机的系统桌面并非同一能力，不可仅凭触点数量推断。

Android 系统返回先关闭当前本地浮层或键盘，不能一次侧滑直接退出远控。仅对必要区域做系统手势排除，不承诺操作系统保留的 Home 与快速切换手势可全部转发。后台运行许可由用户真实系统授权；努比亚现有后台冻结问题不由新界面自动解除。

主工作区与仍可到达的旧会话入口都必须保留功能。多画面选择/布局、源切换、相机切换、文件传输、音频、剪贴板、后台策略、重连、权限诊断都需要可发现的入口。关闭某个画面或整个会话的语义必须清楚，不能因精简把共享连接中的其他工作一并停止。

验收使用实际 Android 程序截图和真实触摸结果，覆盖手机/电脑来源、竖横屏、输入法、缩放与复位、四角映射、手柄拖动、返回/桌面、多指、取消和错误。预览图及编译成功不代表实机通过。
