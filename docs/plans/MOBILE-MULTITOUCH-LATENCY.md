# 局域网低延迟与手机多点直触 · 2026-11-06

用户已回复“按此方案继续”。后续需求清楚即直接实施，不再重复确认是否执行。

用户最新要求：20 ms、5 ms 的低延迟目标有同一 Wi-Fi、两端链路良好的前提，不能套到跨网或弱网。持续降低交互延迟；手机控制手机时自动支持多点直触，保留摇杆、转向、按键同时操作的语义。

## 当前事实与计量

- 正式桌面 130／Android 82 已安装并发布。现有软件时钟测量经过两段 Relay，不能代表局域网单程或物理 glass-to-glass，也不能直接除以二。
- 输入、采集、编码、网络、解码及呈现分别计时；编码 6 ms 不写成端到端 6 ms。记录路由、Wi-Fi 条件、分辨率、帧率、屏幕刷新率与 P50／P95／最大值。同一局域网良好条件单独作为低延迟目标场景；跨网和弱网报告实际分布及恢复行为。
- 优先排查局域网发现、已认证直连与实际媒体路由。用原生硬件路径、最新可见帧、按时释放与有界队列降低排队；压缩帧仍保留有效参考链，不能任意扔掉参考帧。实际显示时序也受屏幕刷新率约束，5 ms 不能仅靠一段软件指标认定。
- 当前 Touch 结构已有 pointer_id，但发送端把它映射成鼠标；手势层把双指捏合留作本地缩放，三指取消；实时持有状态拒绝原生 Touch；Android 接收服务仅保存一根手指。故现状不能宣称手机多点游戏控制已实现。

## 具体实现方案（2026-11-06 已确认）

1. 接收目标按订阅回报原生触摸能力及最大触点数。Android 仅对可控制的屏幕来源、实际已连接的无障碍服务回报支持；摄像头不开放控制。不根据设备名或自定义图标猜测平台。
2. 继续使用现有鉴权、输入租约和来源／几何版本，扩展当前协议的触摸帧及持有触点。每个本地采样帧包含最多 10 个触点变化（平台上限更低时取低值），稳定 pointer_id、Down／Move／Up／Cancel 和归一化来源坐标；同帧变化一起进入公共输入队列。
3. 只有已收到并接受的 Down 才能接收后续 Move／Up。序号防重复，持有心跳只续已有触点，不能凭心跳制造按下；断线、超时、旋转、来源／几何切换或用户接管释放全部触点。队列只合并连续纯移动帧到最新位置；保持按下和抬起顺序，过载时明确释放，避免卡住摇杆或按键。
4. 手机目标默认“多点直触”：所有触点，包括双指缩放，交给远端手机，不自动改成滚轮、右键或本地缩放。HUD 保留触摸板选择，增加简短的“调整画面”操作供本地缩放和平移；切换模式先释放当前远端触点。电脑目标维持现有鼠标和本地缩放行为。
5. Android 复用现有 AccessibilityService 和 GestureDescription，按触点维护连续笔画，单次原生提交同时包含全部活动触点；未移动的手指也继续保持，单指抬起不释放其它手指。合并待提交移动，避免为每根手指逐项等待一段手势回调。不新增 root、ADB 注入或自动系统授权后端。
6. 公共几何保持唯一逆变换：可见矩形 → 当前帧裁剪 → 来源像素，黑边不产生触点；旋转、键盘挤压、缩放、拖拽都使用该帧几何。Android 的无障碍 API 不提供任意压力／工具类型注入，不将协议里的 pressure 当作已实现真实压感。
7. 统一当前协议升级所有自有设备，沿用现有构建、签名和部署入口，不增加旧协议兼容分支或新的发布门槛。

## 验收

纯状态回归覆盖两指／五指交错按下、同时移动、单指抬起其余保持、丢失／重复／过期消息、移动合并、断线取消和几何变化。Android 实机用专用触点记录页面独立记录事件与坐标，验证“一指持续拖动＋另一指连续点击”、双指缩放与旋转后的落点；再测实际手游操作。先证明事件正确，再比较良好同 Wi-Fi 下的输入延迟与画面延迟，保留原始样本，不以本地模拟或提交完成替代远端实际效果。系统屏幕会话授权仍由机主完成。

Android 官方依据：[多笔画构造](https://developer.android.com/reference/android/accessibilityservice/GestureDescription.Builder#addStroke(android.accessibilityservice.GestureDescription.StrokeDescription))、[连续笔画](https://developer.android.com/reference/android/accessibilityservice/GestureDescription.StrokeDescription#continueStroke(android.graphics.Path,%20long,%20long,%20boolean))。原生 API 支持多笔画和按住延续，但这不构成任意游戏性能已经达标的证据。
