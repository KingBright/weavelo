# 远控应用图标和设备角标

独立应用窗口保留应用原图，在右下角叠一枚设备角标。MacBook 用笔记本轮廓，Mac Studio 用主机轮廓，Windows 用四格窗，Linux 用企鹅。整屏会话直接使用设备图标。窗口标题沿用应用名与设备名，Dock 的悬停名称与菜单仍可定位具体设备。

设备名称旁增加「设备角标」。默认按来源机器的系统和机型选择，也可以选择内置样式或导入自定义图片。导入沿用系统文件选择器，将 PNG、JPEG 或 WebP 归一为透明背景的 64 × 64 PNG，限制输入体积和解码尺寸。设置由本机保存，预览立即更新，接收方下次打开或切换来源时读取新标志。

来源选择器继续使用现有 64 × 64 缩略图。确认打开一个来源后，接收端通过同一个已认证的会话发起一次外观请求，携带当前来源和请求编号。来源端从该来源绑定的应用读取最多 256 × 256、256 KiB 的原生 PNG，并返回设备样式或最多 64 × 64、16 KiB 的自定义角标。仅查询当前有效来源，按内容哈希缓存；连接、来源或请求已变化时丢弃旧回包。屏幕和摄像头可以返回设备角标，应用原图字段为空。

新增外观请求与应答，沿用现有控制消息分片、会话鉴权、原生图标读取和发布流程。图标读取、解码与合成只在资产变化时运行，Dock 使用现有每会话辅助进程。显示路径保留原图的比例、颜色和透明边缘。默认标志预览覆盖 Dock 小尺寸和 Retina 尺寸。

验收使用 MacBook 和 Mac Studio 的实际 Dock。对比同一应用在两台机器上的图标，检查 Windows 和 Linux 来源的默认标志，保存一个自定义图标并重开会话确认同步。验证切换应用后图标正确更新，关窗后对应 Dock 项退出。保留源目录、输入、音视频和关闭行为。

## 本地验证

本地合成、预设和图片导入已通过相关检查。用原生可执行程序的 Dock 辅助进程载入两张 256 像素的 ChatGPT 图标，实际 Dock 截图可区分 MacBook 与 Mac Studio 的角标，两个测试项均已退出。图片导入与偏好测试通过，签名发布回归共 1,046 项，19 项跳过。跨设备外观请求待确认，现场运行版本为 124。
