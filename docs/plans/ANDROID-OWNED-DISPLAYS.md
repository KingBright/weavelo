# Android 自有显示与控制

2026-11-06 用户要求直接实现。采集、输入、应用与虚拟显示生命周期归属移动端 Weavelo；Octendra 只承担消息触达和维护，不是运行时依赖。不再另设方案确认环节。

## 产品行为

设备来源区分“手机屏幕”和“独立应用”。前者跟随物理手机的当前内容；后者在 Weavelo 持有的独立虚拟显示中运行，物理屏幕可继续使用其它应用。虚拟显示仍使用同一个 Android 用户和应用数据，并非虚拟机或应用克隆。已在主屏使用的应用、禁止多实例或副屏运行的应用必须按实际能力处理，不能无提示抢走主屏任务。

普通 MediaProjection 路径继续遵守系统对每个新会话的确认。Android 14 的单应用分享只限定采集范围，不等于独立后台运行。自动路径由已经通过设备本人调试授权的 Weavelo 本机辅助进程提供；不自动授予权限、不更改安全策略、不复用 Octendra 的调试密钥或服务。

## 最小实现顺序

1. 将显示辅助进程打包进 Weavelo APK，通过已授权 ADB 启动。辅助进程只与当前 Weavelo UID 通信，Binder 提供结构化的显示、应用和输入操作，没有通用命令执行接口。首次启动借助电脑属于维护步骤；视频和控制持续运行不经过电脑或 Octendra。
2. 先将整屏镜像的 Surface 接入现有 GPU 裁剪、MediaCodec HEVC、会话鉴权与传输，复用现有屏幕尺寸、输入所有权、控制适配器和断线释放。系统停止辅助进程时准确撤销来源，不能继续显示为可拉取。
3. 接入独立应用来源：每个来源持有虚拟显示、采集代际和输入目标；公共订阅与几何逻辑共用，显示必须具备独立焦点且不抢主屏焦点。接收端触摸、键鼠和文本绑定该显示，禁止用“当前主屏”代替选中的应用。
4. 自启动与恢复使用 Weavelo 自己已获授权的连接和生命周期。调试授权被撤销、重启或系统关闭无线调试时如实报告实际恢复条件，不宣称普通 APK 无条件永久拥有 shell 权限。

只通过 GPU Surface 传递实时画面，按需启动原生硬件编码；不增加 CPU 截图转码、逐事件 adb 子进程或网络控制代理。保留来源颜色、旋转、裁剪与逐帧几何，延迟分别记录采集、编码、网络、解码和呈现。

## 实机完成条件

两部手机分别验证整屏自动订阅、USB 拔出后的持续串流、独立应用与主屏并行、多指和文本输入、缩放与旋转、会话结束和辅助进程退出时释放。只在真实同 Wi-Fi 且链路条件良好时评估低延迟目标；软件阶段计时不等于 glass-to-glass。能力缺失保留具体失败和接续步骤，不以源码或接口存在代替设备验收。

参考现有自有代码的显示上下文与焦点处理时保留 Mika / scrcpy 的 Apache-2.0 声明。来源：[Android MediaProjection](https://developer.android.com/media/grow/media-projection)、[Android DisplayManager](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/android16-release/core/java/android/hardware/display/DisplayManager.java)。

旧的 [USB 托管来源方案](ANDROID-USB-MANAGED-CAPTURE.md)仍不实施；本方案的设备身份、传输和运行时均由手机 Weavelo 持有。

## 2026-11-06 实施进展

整屏自动采集已随 Android 86 和桌面 135 安装至两部手机及四台电脑。Windows 与两台 Mac 已看到两部手机的真实画面；红米→努比亚的全屏拉取和单指点击已验证。电脑键盘输入 `abc你好🙂`、鼠标点击与拖动已在红米验证。仍不等于游戏多指、同 Wi-Fi 低延迟或全部设备组合验收。

Android 87 正在接入独立应用：来源使用现有 Window 标识；每个被选择的应用拥有自己的显示、GPU Surface、编码器与输入目标，暂停保留应用任务，结束订阅释放所属显示。已有运行任务会明确拒绝新开，避免迁移主屏应用；开启失败仅终止对应订阅，不撤销整个手机的屏幕共享。帮助进程的键鼠接口限定 Weavelo UID 和自己持有的应用显示，不允许全局电源等按键。普通主屏继续使用已授权无障碍通道；独立应用的 Unicode 文本只写入该显示、该应用的明确可编辑焦点，不使用全局输入法连接。

当前检查包括独立来源几何与代际隔离、暂停保留订阅、输入切源撤销旧所有权、Unicode 选择区边界。87 的真机验证尚未完成；独立应用图标、应用旋转与输入法差异、全自动音频、重启后恢复仍需继续。当前独立显示尺寸变化时拒绝旧坐标输入，不能把这一点报告为旋转完整支持。
