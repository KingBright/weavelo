# Computer-use 整合进展 · 2026-11-05

用户授权将 MacBook 上 Agent 的实现全部整合到当前主 main，后续测试和维护由本任务接管。来源为 MacBook 原始提交 `d374878` 和 `e047259ea82fde6014df962d195b9db86f70237f`；整份源码差异已保存在任务证据目录，未覆盖其它任务或设备身份。

## 当前实现

- 保留既有会话、输入授权及真实调用进程校验。补齐批量操作、双击／三击、组合键、已提交文本、等待、观察帧区域放大、观察引用、操作标记和本地 stdio MCP。
- 操作坐标统一为已观察图像的 `0..65535`；区域放大及快照边界使用明确标注的 `0..1000`。裁剪图像按该帧不可变几何换回完整来源，几何变化使旧观察失效。引用解析显式转换坐标，不根据数值大小猜测坐标系。
- 等待不持有会话锁；每个输入事件在同一短锁内重新校验并派发。用户接管先释放 AI 输入，再排入用户事件；旧任务不能在接管后补发操作。等待画面稳定按批次中的实际位置执行，Mac 使用 GPU 缩小后最多读回 256×256 像素。
- PNG 使用已有图像编码实现的快速压缩。stdio 每行限 1 MiB，校验 JSON-RPC 初始化、参数及通知；观察默认只读，首次调用必须明确指定设备／来源／连接，连接续期和控制升级关闭原租约后重新观察。
- 本地 MCP 的私有记录仍绑定同 UID、实际程序 SHA 和精确来源；保留既有外部 Octendra 记录，拒绝符号链接，使用私有临时文件原子写入。不修改系统权限或替换认证密钥。
- 浏览器工具明确操作本机 CDP，先列出页面再指定页面 ID；不默认选首个页面，不接受非回环或不同端口的页面端点。复用已有 Tungstenite 实现握手、掩码、控制帧和消息大小限制，限制发现／执行时间及代码大小。浏览器引用绑定本次快照和真实 DOM 节点，旧引用或已移除节点失败。

移除了原实现预设的工具栏、侧栏、交通灯和搜索框节点，以及把查看端自身 AX 树当作远端数据的路径。远端快照现在只报告已经核实的来源画布；明确标注远端语义树不可用，不能声称真实 AX 已完成。

## 已验证与待验证

Mac 主 main：30 项 computer-use 检查、16 项像素检查通过，包含真实 Core Video／Core Image 缩略图的颜色、上下方向、尺寸与未知颜色拒绝；真实回环 WebSocket 测试覆盖明确页面选择、Ping 和非回环拒绝。两组生产 GPUI＋VideoToolbox 合成帧输入回归通过。签名集成发布回归 1,045 项通过、19 项跳过（32.844s）。证据日志：任务目录 `cua-integration-final-regressions.log` 和 `cua-integration-release-regression.log`。

这些检查不是正式程序的真实远端 CUA 验收。尚需已签名程序的 stdio／像素／操作／取消连续验收，MacBook 源码统一、正式打包和部署。Linux／Windows 原生 GPU 帧的观察导出仍明确返回不支持；源端真实无障碍树尚未接入。没有通过 CPU 读取全帧、查看端本机 AX 或虚构节点掩盖这些缺项。

MCP 接口依据官方 [工具协议](https://modelcontextprotocol.io/specification/2025-11-25/server/tools) 和 [stdio 传输](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)，当前明确提供 `2025-11-25` 协议版本；没有另增日常构建／升级审批流程。
