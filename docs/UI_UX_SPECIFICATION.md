# Weavelo Air：桌面与移动端交互规范

2026-11-08。根据用户提供的 V3 预览审查并完善；本规范替代此前 Obsidian / Symphonic 配色和浮层设计。继续使用现有原生 GPUI 与 Android Compose，不替换渲染器或媒体链路。预览图是视觉参考，实机验收另记。

## 视觉与信息层级

管理画布 `#F7F9FB`，白色卡片，蓝色 `#2563EB` 主操作，绿色 `#10B981` 在线状态。正文深色，次要信息灰色；错误、连接中、只读与断开必须有文字含义，不能只靠颜色。保留 Weavelo 的真实应用图标、设备图标和来源图标，不采用预览中的示意品牌标记。

设备列表默认突出设备图标、名称与实际状态。查看、发送、文件、身份/网络详情仍可发现，次级操作按需展开。搜索、网络加入/创建、二维码、邀请、权限诊断、发送中会话和文件任务不可因简化而删除。

所有接收模式默认以画面为主，工具栏按需唤出并自动收起，窗口态与全屏态都不固定占用视频布局空间。

普通串流窗口的网络统计放在“更多 → 显示”中，不常驻覆盖视频。

视频保持原生 GPU 缓冲和真实宽高比。窗口外框与内容区域分开计算；工具栏和手机伴侣栏默认收起，按需作为浮层出现，不预留宽度或高度，不触发视频缩放。IME 的实际避让空间仍从视频与输入共用矩形中扣除。全屏底衬为黑色。禁止把 CPU 转色、降低画质或减少原有能力作为视觉优化。

## 四类控制场景

| 场景 | 常用操作 | 完整功能入口与限制 |
| --- | --- | --- |
| 电脑查看电脑 | 点击顶部细柄临时展开工具栏：来源、文件、更多、全屏 | 本地最小化/还原/关闭保留系统窗口语义；来源选择允许另开独立会话；更多含控制、声音、显示和会话管理 |
| 电脑查看手机 | 按需浮现的返回、桌面、适配操作 | 按真实来源能力显示；独立应用不支持系统桌面时不得发送错误动作；没有远端旋转接口就不显示可用旋转按钮，应用自己请求的旋转仍自动适配 |
| 手机查看电脑 | 按需浮现单行：触控板、直触、键盘、复位 | 更多中保留来源、文件、布局、音频、剪贴板、画质、后台和断开；键盘出现时显示快捷键行 |
| 手机查看手机 | 右侧细柄主动展开返回、桌面、键盘、更多 | 断开位于更多；保留原生多指与视图调整。细柄以小范围触控目标叠加在画面边缘，不为其保留整列空白；仅该局部目标拦截触摸，支持显式点击打开 |

“最多四键”适用于常驻主操作行，不适用于展开后需要完成任务的面板、系统窗口按钮或键盘快捷键。不得通过删除入口满足数字限制。布局狭窄时缩短文字和收纳次级项，不把视频压出窗口。

## 防误触与控制安全

桌面全屏细柄以点击展开，鼠标经过顶部或正在拖动远端窗口不弹出工具栏。细柄可视线为 48×4 逻辑像素，命中区域适当扩大；本地按钮事件不透传到远端。退出全屏、关闭面板、切来源、失焦和尺寸变化继续使用现有输入释放/几何版本保护。

移动端细柄向内拖动才打开；竖向移动用于调整位置。控件接管手势前取消远端活动手势。Android 系统保留的 Home/快速切换区不能承诺全部转发；只在必要的小区域申请系统返回手势排除，不能禁用全屏系统导航。返回先关闭本地菜单/键盘；远程会话退出需要明确操作，不由一次边缘返回直接断开。

键盘快捷行保留 Esc、Tab、Ctrl、Alt、Shift、Cmd/Meta 等现有能力。粘滞修饰键在 IME 关闭、来源或会话变化、取消和组件销毁时释放，绑定原会话令牌，不能释放到新目标。复位表示“恢复适配视图”，不是未经定义的物理像素 1:1。

## 功能保全映射

以 [GUI-PRESERVATION-CATALOG.json](plans/GUI-PRESERVATION-CATALOG.json) 的并集为准，不能以预览或当前简化实现作为完整清单。

| 功能组 | 入口/行为 |
| --- | --- |
| 设备、分组、发现、身份、网络、邀请码/二维码、权限 | 管理窗口/手机控制中心；真实连接与错误状态 |
| 主屏、副屏、应用、相机、刷新、另开来源、并发隔离 | 来源选择器；每个窗口/画面保持自己的设备与来源绑定 |
| 点击、拖动、滚轮、键盘、IME、控制锁、紧急释放 | 原生画面输入 + 更多中的控制面板；桌面 Ctrl+Alt+Esc 保留 |
| 声音、静音、音量、已有麦克风对讲、剪贴板 | 更多中的声音/连接选项；按当前能力禁用并解释不可用项 |
| 文件发送/取回、进度、取消、错误、历史、共享目录 | 文件入口；保留目标身份与活动任务所有权 |
| 分辨率、帧率、码率、适配/填充、缩放/平移、PiP | 显示设置；参数来自真实能力和当前状态 |
| 重连、暂停/后台恢复、明确断开与退出 | 会话面板与状态画面；不能通过伪在线或假成功掩盖失败 |
| 遥测与 AI 观察/控制/暂停 | 按需展开真实指标；自动化控制状态与人工接管提示仍可见 |
| 单实例、认证、稳定签名、设备成员关系、升级 | 原有保护保持；UI 调整不改变持久身份或 OS 授权 |

预览中的 0.8ms/8ms、120fps、4K、HEVC 4:4:4、10-bit、Metal/NVENC 和加密文案均为示意，产品只显示实测或经协议确认的数据。解码或 UI 提交不能标记为物理显示完成。
